# Todo-list App
    this is a todo list api bakend for todo app

# Route and the EndPoints

## /todos

GET : Get the list of all todos in the system
POST: Create new todos

## /todos{id}

GET: Get the todo by id
PUT: Updating todo by their id
DELETE: Deleting todo by their id

##  todos/complete

GET: Get todos and see is task is complete or not
